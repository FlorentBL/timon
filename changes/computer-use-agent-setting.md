An agent can now be allowed to control your computer: switch on Computer use in its Permissions settings (off by default) and a setup card checks what your system needs, then the agent sees your screen and drives the mouse and keyboard on macOS, Windows and Linux (X11), until you stop it with the banner's Stop button or Control+Option+Command+Esc (Ctrl+Alt+Shift+Esc on Windows and Linux).
