An agent can now be allowed to control your computer: switch on Computer use in its Permissions settings (off by default) and a setup card checks what your system needs, then the agent sees your screen and drives the mouse and keyboard on macOS, Windows and Linux (X11), until you stop it with the banner's Stop button or Control+Option+Command+Esc (Ctrl+Alt+Shift+Esc on Windows and Linux). It can only click and type in the applications you list under Allowed applications (an empty list allows nothing), and it can list the open windows and bring one to the front. It reads windows through the system's accessibility first (macOS, Windows UI Automation, Linux AT-SPI) and presses buttons or fills fields by element, without moving your pointer; screenshots and clicks by position remain the fallback. An agent can also ask you to allow an application, and you validate it with one click on a card in the conversation, without opening the settings; only you can press Allow.
